## Summary

Marketing copy stores long-form website text for a product landing page. It is deliberately irrelevant to meal planning and exists to make the naive context meaningfully larger than the registry-guided context.

## How it works

The exported text is verbose on purpose. It imitates the kind of content that often lives near product code and pollutes broad agent context even though it has no bearing on a scheduling task.
